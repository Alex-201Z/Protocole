# Scenes

Place Unity `.unity` scene files here.

Suggested scenes for the MVP:

| Scene         | Purpose                              |
|---------------|--------------------------------------|
| `Boot.unity`  | Initialises game state, loads menus  |
| `Combat.unity`| Main combat encounter scene          |
| `Reward.unity`| Card reward selection screen         |
| `Boss.unity`  | Boss combat scene                    |
